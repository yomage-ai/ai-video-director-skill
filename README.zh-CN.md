# AI 视频导演 Skill

[English](README.md)

把视频、文稿和参考素材附到 Codex 或其他 Coding Agent 的任务中，然后复制下面这段话即可。

## 直接使用

```text
请读取并使用这个仓库中的 AI Video Director Skill：
https://github.com/yomage-ai/ai-video-director-skill

我提供的素材：本任务附件中的视频、文稿和参考文件。
目标平台与画幅：[例如：抖音，9:16]
这条视频想表达的重点：[填写一句话；不确定时请先帮我提炼]
风格要求或参考：[可选]

请自行完成使用这个 Skill 所需的准备和执行工作。先检查素材，只询问确实必须由我补充的输入，然后给我：
1. 内容锁定卡；
2. 导演方案；
3. 当前缺少的必要信息。

我确认后再继续制作。涉及付费、账号登录、系统授权、克隆身份或声音、素材版权时，必须先单独征得我的确认。
最后交付成片、可编辑工程和必要的检查记录。
```

如果 Skill 已经出现在 Codex 的 Skill 列表中，也可以直接说：

```text
使用 $ai-video-director 处理我附上的口播视频。先检查素材，再给我内容锁定卡和导演方案；我确认后再继续制作。
```

需要可复用语义进度组件时，可以补充：

```text
使用通用 RMCU 语义进度组件，根据目标画幅选择横屏或竖屏版本；两种方向保持同一套极简双层样式，未激活的长章节标题用省略号，只有当前标题溢出时才循环滚动。
```

## 用户需要提供

- 真人口播视频或待制作的视频文稿，至少提供一种。
- 目标平台、画幅和视频用途。
- 必须保留的观点、内容或素材。
- 可选的参考视频、品牌素材和风格偏好。
- 对付费、账号权限、身份/声音使用和素材权利的明确授权。

除此之外，其他准备和执行工作都由 Agent 按 Skill 内部规范自行完成。

当前仓库用于私有测试，尚未授予公开使用或商用许可证。不要把私人原片、脸、声音、账号凭据或未发布成片提交到这个 Git 仓库。
