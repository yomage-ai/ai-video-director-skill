# AI 视频导演 Skill

[English](README.md)

把视频、文稿和参考素材附到 Codex 或其他 Coding Agent 的任务中，然后复制下面这段话即可。

## 直接使用

```text
请读取并使用这个仓库中的 AI Video Director Skill：
https://github.com/yomage-ai/ai-video-director-skill

我提供的素材：本任务附件中的视频、文稿和参考文件。
目标平台与画幅：[例如：抖音，9:16]
这条视频想表达的重点：[填写一句话；不确定时请先帮我提炼]
风格要求或参考：[可选]

请自行完成使用这个 Skill 所需的准备和执行工作。先检查素材，只询问确实必须由我补充的输入，然后给我：
1. 内容锁定卡；
2. 导演方案；
3. 当前缺少的必要信息。

我确认后再继续制作。涉及付费、账号登录、系统授权、克隆身份或声音、素材版权时，必须先单独征得我的确认。
最后交付成片、可编辑工程和必要的检查记录；需要发布时，还要交付带规则核对日期的发布包。
```

如果 Skill 已经出现在 Codex 的 Skill 列表中，也可以直接说：

```text
使用 $ai-video-director 处理我附上的口播视频。先检查素材，再给我内容锁定卡和导演方案；我确认后再继续制作。
```

需要直接用于平台发布时，要明确真正的发布规格，而不是默认接受审片代理：

```text
目标平台是抖音，9:16，发布版必须是真 2160x3840。剪辑前先锁定发布规格；迭代时可以给我看代理文件，但最终确认前必须用最高质量源素材生成、探测并让我审看准确的 4K 发布候选片。通过 QA 后，再核对当日官方规则，并给我至少三组准确的封面标题、发布文案、标签和 AI 声明方案。
```

处理口播重剪时，Skill 还会逐一核对每个真实片段边界：文案句首句尾完整可听、气口自然、不保留吞咽或口腔杂音，并在粗剪确认前检查正常速度的真实渲染结果。

需要短卡字幕时，可以直接补充：

```text
字幕使用“逗号与句末强制换卡”的短语义卡：每个逗号、句号、分号、冒号、问号和叹号都换到下一张卡；短枚举可以保留顿号，枚举过长继续按语义拆分。禁止按固定字符数切断中文词、英文术语或产品名，卡首不能出现游离标点。
```

展示 App 或工作台证据时，Skill 会先锁定准确的页面、页签与子页签状态，用源界面语义确定截图区域而不是凭缩略图猜框，并保存 ROI 清单；展示了相邻但错误的页面状态或近似标注时会阻断导出。已通过的签名片尾也必须完整继承歪头、眨眼等动作契约，除非新版本再次得到明确确认。

需要可复用语义进度组件时，可以补充：

```text
使用通用 RMCU 语义进度组件，根据目标画幅选择横屏或竖屏版本；两种方向保持同一套极简双层样式，未激活的长章节标题用省略号，只有当前标题溢出时才循环滚动。
```

需要适配多设备的 9:16 竖屏口播版式时，可以补充：

```text
使用已确认的竖屏口播安全版式。可裁切背景保持满幅，但字幕、进度语义、B-roll 重要区域、有明确边界的人物小窗，以及人物中必须保留的脸、手势或身份标识，都要在狭长手机与宽屏平板上可见；以真实发布播放器为准，不能把编码画布边缘当成安全边缘。
```

需要“素材铺底、带描边的实时人物抠像”时，可以补充：

```text
使用 B-roll 铺底；真实动态蒙版通过验收时，把口型同步的人物做成带描边的透明抠像。先声明人物属于前景、辅助还是背景层，再独立选择贴容器底边或贴画布底边。前景人物和有边界小窗要避开其他 UI；有意做成弱背景的抠像可以位于字幕或平台文案之后，但必须保住脸、必要手势、关键证据和身份标识。使用 HyperFrames 在本地处理锁定后的干净 A-roll，对白继续使用统一时间线的音轨；如果边缘不合格，就回退到设计过的人物小窗或全屏证据，不能保留坏抠像。
```

需要避免源片剪点与 B-roll 版式分两次闪现时，可以补充：

```text
统一源片剪点和版式边界：新片段本来就应该位于 B-roll/人物小窗版式时，两者必须在同一个节目帧完成；以整数帧号作为唯一时间源，秒数由 frame/fps 推导，禁止再四舍五入到六位小数。连续信息段使用一条稳定人物层，禁止短暂闪回 A-roll；有意回到 A-roll 时至少稳定两秒。只有逐词同步的画面模式演示可以更短，并在导出前逐帧审计边界。
```

需要沉淀可复用的代码动画时，可以补充：

```text
使用代码动画组件体系。先把已有组件分成通用机制、私人创作者适配、题材模板、历史归档和错误样本；通用行为必须与私人素材及本片文案、时间和素材分离。只有通过内容适配、可定位动画、布局、权利和真实导出检查后，才能复用或升级组件。
```

## 用户需要提供

- 真人口播视频或待制作的视频文稿，至少提供一种。
- 目标平台、画幅和视频用途。
- 必须保留的观点、内容或素材。
- 可选的参考视频、品牌素材和风格偏好。
- 对付费、账号权限、身份/声音使用和素材权利的明确授权。

除此之外，其他准备和执行工作都由 Agent 按 Skill 内部规范自行完成。

当前仓库用于私有测试，尚未授予公开使用或商用许可证。不要把私人原片、脸、声音、账号凭据或未发布成片提交到这个 Git 仓库。
