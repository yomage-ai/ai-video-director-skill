# AI 视频导演 Skill

简体中文 | **[English](README.md)**

把下面这段话复制给 Codex 或其他 Coding Agent。附上录制视频或提供本地路径；文稿和风格参考可选：

```text
优先使用我已安装的本地 $ai-video-director Skill。如果没有安装，再读取并使用这个仓库：
https://github.com/yomage-ai/ai-video-director-skill

我提供的素材：[视频附件或本地路径；有文稿和参考时一并提供]
目标平台与画幅：[例如：抖音，9:16]
这条视频想表达的重点：[填写一句话；不确定时请先帮我提炼]
风格要求或参考：[可选]

请先在本地检查素材，用中文给我一份人能直接看懂的内容锁定卡和粗剪方案，不要展示内部 JSON。
等我确认后再继续制作。
粗剪锁定后，先给我一个 6-12 秒、包含真实对白和声音设计的精剪样片，再制作完整精剪。
完成后交付成片、可编辑工程和检查记录。
如果需要发布，再提供多套封面标题、发布文案、标签和 AI 声明方案。
沿用本任务已有授权。只有确实新增付费、登录、系统权限、身份或声音使用、素材权利授权时，再请我处理。
```

如果只想做粗剪：

```text
使用 $ai-video-director 处理这段录制视频，只做粗剪：删除口误、重录和多余等待，保留完整发音与自然节奏。先给我内容与粗剪方案；粗剪通过后，交付粗剪视频、可编辑时间线工程和字幕，到此结束。
```

## 用户需要提供

- 真人口播视频，也支持屏幕与摄像头已经录成一张画面的素材。文稿有帮助，但不能代替录制素材。
- 目标平台、画幅和视频用途。
- 必须保留的观点、内容、来源或参考素材。
- 已有的风格偏好或视觉参考；首次确认时不提供也可以。

## 你会得到什么

- 制作前的人类可读内容锁定卡和粗剪方案，不展示内部 JSON。
- 粗剪确认后的短版视听精剪样片，再进入完整精剪。
- 没有提供视觉参考时，Skill 会根据内容从内置公共策展风格库中主动推荐精剪方向。风格库会保留喜欢过和验证过的参考，但不是封闭素材列表；没有条目适配时，Agent 会根据内容重新设计素材、动画、音乐和音效系统。完整制作前仍由你确认或调整。
- 成片及可编辑工程；只做粗剪时，交付批准的粗剪、可编辑时间线和字幕后结束。
- 检查记录和清晰的交付路径。
- 需要发布时的多套发布文案、封面标题、标签和 AI 声明方案。

安装、依赖检查、本地素材检查、转写、时间线审计、风格推荐、素材规划、渲染和验证都由 Agent 处理。风格参考不是必填项；用户没有提供时，Agent 会比较公共策展风格与本片内容和证据需求，不会让用户自己从零发明方向。没有合适条目时，Agent 会在正常确认和版权边界内安排真实证据、生成或代码素材、排版、动效、音乐和音效。首次确认前，Agent 不会无必要地上传大文件、反复尝试云端导入、完整渲染或提前制作风格方案。

当前版本会核对实际媒体、处理参数、批准和版本。不支持的编辑器效果会停止交接，由 Agent 安排明确转换或已审定的高质量衍生源。勾选字段和渲染成功不能代替听审。`0.2.0-rc.1` 已通过工程回归检查，作为候选版本共享；下一条独立实片仍需验证听感、返工和完整长片资源占用。实际进度见 [验证状态](PROJECT_STATE.json)。
