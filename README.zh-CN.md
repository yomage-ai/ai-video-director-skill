# AI 视频导演 Skill

[English](README.md)

把视频、文稿和参考素材附到 Codex 或其他 Coding Agent 的任务中，然后复制下面这段话即可。

## 直接使用

```text
请读取并使用这个仓库中的 AI Video Director Skill：
https://github.com/yomage-ai/ai-video-director-skill

我提供的素材：本任务附件中的视频、文稿和参考文件。
目标平台与画幅：[例如：抖音，9:16]
这条视频想表达的重点：[填写一句话；不确定时请先帮我提炼]
风格要求或参考：[可选]

请自行完成使用这个 Skill 所需的准备和执行工作。先检查素材，只询问确实必须由我补充的输入，然后给我：
1. 内容锁定卡；
2. 导演方案；
3. 当前缺少的必要信息。

我确认后再继续制作。涉及付费、账号登录、系统授权、克隆身份或声音、素材版权时，必须先单独征得我的确认。
最后交付成片、可编辑工程和必要的检查记录。
```

如果 Skill 已经出现在 Codex 的 Skill 列表中，也可以直接说：

```text
使用 $ai-video-director 处理我附上的口播视频。先检查素材，再给我内容锁定卡和导演方案；我确认后再继续制作。
```

处理口播重剪时，Skill 还会逐一核对每个真实片段边界：文案句首句尾完整可听、气口自然、不保留吞咽或口腔杂音，并在粗剪确认前检查正常速度的真实渲染结果。

展示 App 或工作台证据时，Skill 会先锁定准确的页面、页签与子页签状态，用源界面语义确定截图区域而不是凭缩略图猜框，并保存 ROI 清单；展示了相邻但错误的页面状态或近似标注时会阻断导出。已通过的签名片尾也必须完整继承歪头、眨眼等动作契约，除非新版本再次得到明确确认。

需要可复用语义进度组件时，可以补充：

```text
使用通用 RMCU 语义进度组件，根据目标画幅选择横屏或竖屏版本；两种方向保持同一套极简双层样式，未激活的长章节标题用省略号，只有当前标题溢出时才循环滚动。
```

需要适配多设备的 9:16 竖屏口播版式时，可以补充：

```text
使用已确认的竖屏口播安全版式。可裁切背景保持满幅，但字幕、进度语义、B-roll 重要区域、人物画中画或人物抠像和身份标记必须在狭长手机与宽屏平板上都完整可见；以真实发布播放器为准，不能把编码画布边缘当成安全边缘。
```

需要“素材铺底、带描边的实时人物抠像”时，可以补充：

```text
使用 B-roll 铺底；真实动态蒙版通过验收时，把口型同步的人物做成带描边的透明抠像。使用 HyperFrames 在本地处理锁定后的干净 A-roll，对白继续使用统一时间线的音轨；如果边缘不合格，就回退到设计过的人物小窗或全屏证据，不能保留坏抠像。
```

需要沉淀可复用的代码动画时，可以补充：

```text
使用代码动画组件体系。先把已有组件分成通用机制、私人创作者适配、题材模板、历史归档和错误样本；通用行为必须与私人素材及本片文案、时间和素材分离。只有通过内容适配、可定位动画、布局、权利和真实导出检查后，才能复用或升级组件。
```

## 用户需要提供

- 真人口播视频或待制作的视频文稿，至少提供一种。
- 目标平台、画幅和视频用途。
- 必须保留的观点、内容或素材。
- 可选的参考视频、品牌素材和风格偏好。
- 对付费、账号权限、身份/声音使用和素材权利的明确授权。

除此之外，其他准备和执行工作都由 Agent 按 Skill 内部规范自行完成。

当前仓库用于私有测试，尚未授予公开使用或商用许可证。不要把私人原片、脸、声音、账号凭据或未发布成片提交到这个 Git 仓库。
