# AI 视频导演 Skill

简体中文 | **[English](README.md)**

用于口播视频剪辑的 AI Video Director Skill，支持从视频、文稿和参考素材生成可审片、可编辑的成片。

## 直接使用

把视频、文稿和参考文件附到 Codex 或其他 Coding Agent 的任务中，然后复制：

```text
请读取并使用这个仓库中的 AI Video Director Skill：
https://github.com/yomage-ai/ai-video-director-skill

我提供的素材：本任务附件中的视频、文稿和参考文件。
目标平台与画幅：[例如：抖音，9:16]
这条视频想表达的重点：[填写一句话；不确定时请先帮我提炼]
风格要求或参考：[可选]

请先检查素材，给我内容锁定卡和导演方案。
等我确认后再继续制作。
完成后交付成片、可编辑工程和检查记录。
如果需要发布，再提供多套封面标题、发布文案、标签和 AI 声明方案。
涉及付费、账号登录、系统授权、身份或声音克隆、素材版权时，请先单独征得我的确认。
```

如果 Skill 已经出现在 Codex 的 Skill 列表中：

```text
使用 $ai-video-director 处理我附上的口播视频。先给我内容锁定卡和导演方案，等我确认后再继续制作。
```

## 用户需要提供

- 真人口播视频或视频文稿。
- 目标平台、画幅和视频用途。
- 必须保留的观点、内容、来源或参考素材。
- 可选的风格偏好或视觉参考。

## 你会得到什么

- 制作前的内容锁定卡和导演方案。
- 成片，以及所选工具支持时的可编辑工程。
- 检查记录和清晰的交付路径。
- 需要发布时的多套发布文案、封面标题、标签和 AI 声明方案。

完成必要确认后，其余准备和执行工作由 Agent 处理。
